# GWEB Merchant Onboarding — Frontend

Vite + React + TypeScript SPA for the merchant onboarding wizard. See the repository
root [`README.md`](../README.md#frontend) for how to run this against the backend, and
[`docs/adr/0010-frontend-architecture.md`](../docs/adr/0010-frontend-architecture.md)
for the full stack rationale.

```bash
npm install
npm run dev      # http://localhost:5173, proxies /v1 to the backend on :5243
npm run build    # static bundle in dist/
```
